- 방법: `kg-model-bench` 스킬 절차. 대표 12문서(장애·인과·과거·운영·위키 아키텍처 혼합) 추출 벤치 + 6문항 질의 벤치.
- 비용 proxy: 전체 처리 시간 (구독 CLI 라 달러 청구 없음 — rate limit 도달 0회).
- 축약 사항: 스킬 기준 파일럿 30건 대신 12문서 사용 (시간 관리), haiku 는 질의 벤치 제외 (추출 벤치 탈락으로 판단 종료).

## 반영

- `.env` 기본값: 추출 `LLM_MODEL=gpt-5.5`, 질의 API `LLM_MODEL=gpt-5.6-sol` + `LLM_REASONING_EFFORT=low`.
- 캐시는 `<model>@<effort>` 로 분리되어 벤치·모델 전환 간 오염 없음.
- 전량 537문서 추출 예상 시간: gpt-5.5 기준 약 2시간 (동시 4).
