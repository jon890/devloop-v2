Architecture & delivery report

코드가 말하지 않는 이유를 되찾는 시스템

Dooray 업무·댓글·위키와 OCR Git 이력을 하나의 증거 흐름으로 묶고, Coding Agent가 필요한 순간에만 과거 결정과 제약을 한 번의 검색으로 회수하도록 구현했습니다. Memory는 원문을 대체하지 않으며 모든 결과는 안정 식별자와 원문 링크로 되돌아갑니다.

최종 목표

출처를 검증할 수 있는 Experience Memory와 재현 가능한 평가 경로를 완성했습니다. 지식 추출과 LLM 검색은 gpt-5.6-luna / low로 고정하고 fallback하지 않습니다. 실측 이득이 확인되지 않은 Graph와 automatic retrieval은 production 기본값으로 채택하지 않습니다.

Provenance spine

현재 아키텍처

저장은 계층적이어도 production 검색 표면은 평평하게 유지합니다. Graph와 automatic 경로는 같은 source lock과 task로 분리 측정하며, 채택 전까지 실험 조건으로 남깁니다.

Dooray + Git

업무, 댓글, 위키와 9개 OCR 저장소를 읽기 전용으로 수집합니다.

Evidence

원천별 형식을 stable ID와 HTTP source ref를 가진 packet으로 정규화합니다.

Luna extraction

Decision, Constraint, Incident, Failed Attempt, Lesson을 추출합니다.

Compact Wiki

Markdown과 status-aware JSON index를 결정적으로 생성합니다.

Lexical search

LLM 없이 단일 CLI에서 얕고 측정 가능한 기준선을 제공합니다.

Safe retrieval

voluntary lexical을 기본으로 사용하고 automatic은 active·high·current 결과만 허용합니다.

Evaluation gate

no-memory, triggered, oracle, Graph, automatic의 성공·비용·오염을 같은 source lock에서 비교합니다.

비공개 실행 영역

source lock, 실제 경로와 revision, transcript, query, Memory ID, attempt workspace를 Git 비추적 영역에 격리합니다.

privacy gate

공개 가능한 보고 영역

task ID, 집계, 판정, 해시만 내보냅니다. 원문 접근 링크는 실제 Memory 응답에 보존하고 공개 보고서에는 내부 주소를 노출하지 않습니다.

Operating contract

구현 원칙

확장성은 계층을 늘리는 대신 경계를 선명하게 만드는 방식으로 확보합니다.

원천으로 되돌아감

Memory 항목은 stable source ID와 HTTP 링크를 함께 가진 파생물입니다. 결론이 의심스러우면 언제든 원문을 확인할 수 있습니다.

관심사별 단방향 흐름

정규화, LLM 추출, Wiki 생성, 검색, 평가가 서로의 내부 저장 형식을 침범하지 않습니다.

측정 후 채택

vector, graph, automatic retrieval은 기능 목록이 아닙니다. lexical·voluntary 기준선보다 나은 경우에만 도입합니다.
