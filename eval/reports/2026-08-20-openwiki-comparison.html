이력과 현재 계약 결합

5MB·20MB 업로드

붙여 쓴 단위와 혼합 언어 질의에서는 누락됐다. 숫자 단위를 분리하고 추출 언어를 맞추면 2위로 검색됐다.

생성 전에 드러난 세 가지

아직 비교하지 못한 것

Dooray 최신성이 부족하다

이번 원본 스냅샷에는 검토 대상인 일부 최신 업무가 없었다. 최신 수집 뒤 같은 추출을 다시 수행해야 한다.

정면 품질 비교는 미완료다

OpenWiki 생성물이 없어 답변 정확성, 인용 충실도, 생성 시간과 문서 크기를 같은 조건에서 채점하지 못했다.

비용을 측정할 수 없다

OpenWiki 0.3.3의 openai-chatgpt 경로는 실행별 토큰 수와 비용을 출력하지 않는다.

최종 목표

코딩 에이전트가 작업 전에 과거 결정, 호환성 제약, 장애 원인, 마이그레이션 맥락을 빠르게 찾고 원문까지 검증할 수 있는 지식 저장소를 구축한다.

  • Dooray 업무·댓글·위키와 OCR Git 저장소 전체를 사용한다.
  • 우리 추출·LLM 검색 경로는 gpt-5.6-luna만 허용하고 실패 시 승격하지 않는다.
  • 정규화와 어휘 검색은 결정적으로 유지한다.
  • Memory마다 원천 종류, 식별자, 개정 또는 시각, 직접 링크를 보존한다.
완료 기준

다음 실행에서 닫을 것

  1. Codex 계정 한도 회복 뒤 gpt-5.6-sol 최소 호출을 확인한다.
  2. 임시 복제본에서 AGENTS.md 심볼릭 링크를 일반 파일로 격리한다.
  3. OpenWiki 생성 파일 수와 바이트, 시간을 기록한다.
  4. Claude가 위키만 사용해 네 질문에 답한다.
  5. 코드·시험·ADR 정답지와 정확, 부분, 오류, 근거 없음으로 대조한다.

공개 보고서에는 사내 URL과 원문을 포함하지 않았다. 원본 OCR 저장소는 읽기 전용으로 유지했으며 모든 비교 산출물은 격리된 실행 경로에서 만들었다.
