# 함정 색인

**반복되는 실수 패턴**을 활동별로 모았다. 그 활동을 시작하기 전에 해당 파일을 읽는다.

읽는 시점이 "그 일을 하기 직전" 이라 활동별로 갈랐다. 주제별로 가르면 어느 파일을 열어야 할지 모른다.

| 파일 | 언제 읽나 | 담긴 함정 |
| --- | --- | --- |
| [measurement.md](measurement.md) | `kg-eval` 로 품질을 재기 전 | 1회 측정 금지, 총수가 안 움직일 때의 분해, 부분 재측정, 측정용 API 의 `EPIPE`, 기준선 한계 |
| [graph-loading.md](graph-loading.md) | `sync-neo4j`·`reset-neo4j` 를 돌리기 전 | MERGE 전용, 되돌릴 수 없는 적재의 예측 절차, 관계 추가 시 질의 쪽 확인, 오탐 제거가 지표를 낮추는 것 |
| [testing.md](testing.md) | 테스트를 추가하거나 통과를 근거로 삼기 전 | 조용한 `exit 0`, glob·목록 누락, 조건부 건너뜀, 가드는 변이로 검증 |
| [process-cleanup.md](process-cleanup.md) | 컨테이너·워크트리를 만들거나 지우기 전 | `compose down` 이 프로젝트 전체를 지움, 워크트리 계정, `git add -A`, 포맷터 전체 실행 |
| [spec-writing.md](spec-writing.md) | phase 파일이나 구현 지시를 쓰기 전 | 대표형만 보고 전수 확인 안 함, 코드가 받는 값 대신 원천을 봄, 없는 데이터를 요구함 |

## 세 문서 계열의 경계

| 폴더 | 성격 | 언제 쓰나 | 언제 읽나 |
| --- | --- | --- | --- |
| `docs/retrospectives/` | **사건 하나**를 깊게. 관찰·원인·조치 | 사건 직후 1회. 이후 고치지 않는다 | 그 사건을 되짚을 때 |
| `docs/pitfalls/` | **반복 패턴**을 짧게. 하지 말 것과 대신 할 것 | 같은 유형이 두 번째 나올 때. 계속 갱신한다 | 그 활동을 시작하기 전 |
| `CLAUDE.md` | 지금 지켜야 할 규칙과 구조 | 규칙이 바뀔 때 | 매 세션 |

회고의 frontmatter 에 `promotion: 승격` 이 있다. **그 승격 대상이 이 폴더다.**

## 작성 규칙

- **하지 말 것과 대신 할 것을 한 쌍으로** 적는다. 서술만 있으면 행동으로 안 옮겨진다
- **실측 수치를 함께 남긴다.** "느려진다" 가 아니라 "36회 중 35회가 실패했다" 로 적는다
- 같은 정보를 `CLAUDE.md` 와 두 곳에 두지 않는다. 옮기고 복사하지 않는다

## 알아 둘 한계

**가까이 둔다고 예방되지 않는다.** `noclobber` 함정은 전역 `CLAUDE.md` 에 이미 적혀 있었는데
그대로 걸린 사례가 있다. 이 폴더의 실제 값은 상시 예방보다 **활동 직전의 점검표**와
**일이 터진 뒤의 진단 참조**에 있다.

실수를 실제로 잡은 것은 둘이었다 — **독립 검토**와 **측정**이다.
