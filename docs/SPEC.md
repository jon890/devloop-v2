깊이 인터뷰(8라운드, 최종 모호도 13%)로 확정한 요구사항이다.
원본 인터뷰 기록: `~/personal/.omc/specs/deep-interview-dooray-knowledge-graph.md`

## Goal

Dooray `tc-ocr` 프로젝트의 업무·위키를 수집해,
고정 온톨로지 스키마에 따라 지식그래프(Neo4j)로 적재하고,
자연어 관계형 질문에 근거 서브그래프 시각화와 함께 답하는
백엔드·프론트엔드 포함 MVP 를 만든다.
기저 동기는 GraphRAG·온톨로지·그래프 DB 기술 학습이다.

## Constraints

- 구현 위치: `~/personal/devloop-v2` (이 저장소).
- 스택: TypeScript 단일 — NestJS(파이프라인+API), LangChain.js(선택적), Neo4j(docker-compose), React(프론트).
- LLM 은 구독 계정 CLI 경유만 허용 — 종량제 API 금지.
  - 1순위: `codex exec` (OpenAI Codex 계정 연동)
  - 허용: `claude -p` (Claude Code 헤드리스)
  - CLI 어댑터 인터페이스로 추상화해 교체 가능하게 한다.
- 실행 환경: 로컬 맥. Neo4j 는 docker-compose.
- Dooray 접근: 기존 `dooray-cli`(`@bifos/dooray-cli`, `~/.dooray` 설정) 재활용 — child_process 로 호출.
- 온톨로지: 고정 스키마 (PLAN.md 의 공유 계약 참조). LLM 은 스키마 틀 안에서 추출만 한다.

## Non-Goals

- 증분 동기화 — 전량 재실행으로 갈음.
- 여러 프로젝트를 한 그래프에 동시 통합.
  단, 파이프라인은 `--project` 파라미터로 다른 프로젝트를 색인할 수 있어야 한다 — 품질 일반화 루프(색인→검색→품질 확인 반복)가 목표이기 때문이다.
- Milestone 축 모델링 — 팀이 마일스톤을 잘 쓰지 않아 이번 계획에서 제외 (2026-07-22 사용자 확인).
- 온톨로지 스키마 자동 진화.
- 사내 배포·멀티유저 서비스화 — 로컬 개인 도구.
- 벡터 유사도 검색 대체 (nbrain 영역) — 관계형 질문·히스토리 추적에 집중.
