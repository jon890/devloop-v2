# fulltext preflight가 숫자 식별자를 그래프 실패로 만들었다

## 관찰

Phase 04 첫 기준선 raw 실행은 36회까지 완료됐지만 30회가 `GRAPH` 실패였다.
원시 파일은 `eval/runs/plan005-baseline-preflight-failure.json`로 보존했다.

## 원인

평가 실행기의 그래프 사전검사가 업무 번호와 댓글 id 같은 숫자 식별자를 fulltext 검색으로 해석했다.
식별자 조회와 자연어 검색의 목적이 다른데 같은 경로로 처리했다.

## 영향

실제 그래프에는 필요한 노드가 있었지만 평가 실행기는 문항 대부분을 그래프 도달 실패로 판정했다.
이 상태로 보고서를 만들면 검색 품질 기준선이 아니라 실행기 사전검사 결함을 기준선으로 고정하게 된다.

## 대응

통합 수정 커밋 `5749ac1` 뒤 동일한 baseline 명령을 다시 실행했다.
새 실행은 36회 모두 완료됐고 `GRAPH` 실패가 0건이었다.

## 검증

새 raw 실행은 36회 모두 HTTP 201이며 오류가 0건이다.
경계 분포는 `RETRIEVAL` 19건, `NONE` 15건, `ANSWER` 2건, `GRAPH` 0건이다.

## 배운 점

평가 사전검사는 자연어 검색이 아니라 안정 식별자 조회 계약을 따라야 한다.
완료된 raw 파일도 실행 조건 결함이 있으면 보존하고 새 기준선과 분리해야 한다.

## 후속

일반 규칙으로 승격하지 않는다.
이번 회고와 보존 raw 파일이 재발 시 대조 근거를 소유한다.
