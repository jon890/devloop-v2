# 지식그래프 평가 질문 세트 (tc-ocr 실측 기반)

> **최신 평가 세트는 `eval/questions-human-tc-ocr.json` · `eval/questions-ai-tc-ocr.json` 이다.**
> 이 문서는 질문의 배경(기대 근거·검증 축)을 사람이 읽기 위한 해설이며,
> 난이도 사다리(L1~L5)·채점표·통과선은 `docs/EVAL-RUBRIC.md` 를 따른다.

2026-07-22 tc-ocr 실데이터(업무 490건·위키 47건)에서 추린 대표 후보 7개의 해설이다.
각 질문은 벡터 유사도 검색으로는 답하기 어렵고, 여러 노드를 관계로 엮어야 답이 나오는 유형이다.

## 후보 질문

### Q1. 모델 연결 실패 이력 종합

> "General OCR 모델 연결 실패·다운 관련 업무들과 담당자, 참고할 위키 문서를 연결해줘."

- 기대 근거: 업무 485(모델 서버 40분 다운), 487(ReadTimeout 대량), 489(응답지연 스파이크), 507(연결 실패 구조 개선)
- 위키: "모델 서버 프로세스 구조와 연결 실패 대응"
- 검증 축: Task↔Task 유사 사건 연결 + Task↔Wiki + Task↔Person

### Q2. 결정 히스토리 추적

> "API Gateway 제거는 왜 결정됐고, 그 결정으로 파생된 업무들은 무엇인가?"

- 기대 근거: 491(RST 연결 종료 장애) → 483(제거 결정) → 498(경로 등가성 검증), 504·505·506(공인 진입점 전환)
- 위키: "OCR API Gateway 제거 — 외부 전용 ingress 로 분리한 작업"
- 검증 축: Decision 노드 + 인과 방향 관계

### Q3. 기술 부채 대응 흐름

> "ingress-nginx 유지보수 종료에 어떻게 대응하고 있나 — 관련 업무와 문서는?"

- 기대 근거: 494(chart 업그레이드), 495(Gateway API 이행 검토), 496(rewrite 정규식 이전)
- 위키: "ingress-nginx 컨트롤러를 여러 개 둘 때 격리하는 법"
- 검증 축: Concept(ingress-nginx) 중심 스타 조회

### Q4. 자원 제약 대응 관계망

> "GPU 자원 제약 대응으로 어떤 업무들이 진행됐고 서로 어떤 관계인가?"

- 기대 근거: 501(AMP FP16 도입), 502(추론 최적화 조사 — 501의 후속), 482(GPU 노드 tmpfs 포화), 500(노드 증설 검토)
- 검증 축: Concept(GPU) 매개 간접 연결 + 업무 간 선후 관계

### Q5. 외부 연동 장애 처리

> "CooCoN 같은 외부 연동 서비스 장애 처리 관련 업무와 코드 위치는?"

- 기대 근거: 492(점검/장애 응답 뭉개짐 — DocumentIdCardAuthenticityService:82), 493(log.error 반복 노출 — ExceptionController:45), 484(비허용 국가 차단 오응답 — CabService.authorize:141)
- 검증 축: 본문 속 코드 참조를 Concept 로 뽑는 추출 품질

### Q6. 선행 의존 업무 추적

> "요청 크기 상향 부하테스트를 위해 선행된 업무들은 무엇이고 누가 담당했나?"

- 기대 근거: 497(요청 크기 제한 상향) → 499(부하테스트), 500(노드 증설 — 부하테스트 사전 조건)
- 검증 축: 선행 조건 관계 + Person 연결

### Q7. 시스템 의존 관계

> "OCR.API 가 의존하는 시스템·컴포넌트는 무엇이고, 각각 어느 위키에 정리돼 있나?"

- 기대 근거: 위키 "NCS 모델 L4 LB 커넥션 토폴로지와 OCR.API 커넥션 풀", "OCR.API 백엔드 구조 — 무엇을 하고 어떻게 짜였나", "모델 서버 프로세스 구조와 연결 실패 대응"
- 검증 축: Concept↔Concept `DEPENDS_ON` 관계 + Wiki 근거 연결

## 판정 기준 (질문 공통)

- 답변이 기대 근거 업무·위키의 과반을 인용한다.
- 인용한 근거 노드가 UI 서브그래프에 하이라이트된다.
- 존재하지 않는 업무 번호·문서를 지어내지 않는다.
