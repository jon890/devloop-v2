# ADR 0003 — 필수 설정이 없으면 기동을 실패시킨다

- 상태: 채택
- 결정일: 2026-07-28
- 기록일: 2026-07-29

## 맥락

`.env` 에 질의 모델이 지정돼 있었다.

```
QUERY_LLM_MODEL=gpt-5.6-terra
```

그런데 **API 가 그 파일을 읽지 않았다.** dotenv 를 쓰지 않고 `node dist/main.js` 로 뜨기 때문이다.
실행 중인 프로세스 환경에 그 변수가 없었다.

LLM CLI 어댑터는 모델이 없으면 모델 플래그를 **아예 붙이지 않는다.**

```ts
args: ["exec", ...(model ? ["-m", model] : []), ...]
```

그래서 CLI 기본 모델로 질의가 돌았다. **문서에 확정됐다고 적힌 모델이 아니었다.**

더 나쁜 것은 이것이 드러나지 않은 이유다. 다른 변수들은 코드 기본값이 `.env` 값과 **우연히 같았다.**

| 변수 | 의도 | 실제 |
| --- | --- | --- |
| `NEO4J_URI` | `bolt://localhost:7687` | 코드 기본값이 같아 우연히 정상 |
| `NEO4J_AUTH` | 같은 값 | 코드 기본값이 같아 우연히 정상 |
| `LLM_PROVIDER` | `codex` | `!== "claude"` 분기라 우연히 정상 |
| `QUERY_LLM_MODEL` | `gpt-5.6-terra` | **적용 안 됨** |

넷 중 하나만 달랐고 그 하나가 측정 결과를 좌우했다.

## 결정

**설정을 한곳에 모으고, 필수 값이 없으면 기동을 실패시킨다.**

- `@nestjs/config` 로 저장소 루트 `.env` 를 읽는다
- zod 로 검증하고 검증 실패는 `exit 1` 로 죽는다
- 필수와 선택을 가른다
- 하드코딩된 기본 비밀번호를 없앤다

| 구분 | 값 |
| --- | --- |
| 필수 | `NEO4J_URI`, Neo4j 자격증명, `QUERY_LLM_MODEL` |
| 선택 | `PORT`(3000), `NEO4J_DATABASE`(neo4j), `LLM_REASONING_EFFORT` |
| 기본값과 열거형 검증 | `LLM_PROVIDER` — 기본값 `codex`, `codex`·`claude` 만 허용 |

`LLM_PROVIDER` 를 필수로 하지 않은 이유 — 파이프라인이 기본값을 쓰고 있어 규칙이 어긋나고,
값이 없어서 **조용히 틀린 결과**가 나오는 경우가 아니다. 대신 오타(`codexx`)를 막는 열거형 검증을 넣었다.

## 이유

목적은 값을 한곳에 모으는 정리가 아니다. **부재를 조용한 기본값이 아니라 즉시 드러나는 실패로 바꾸는 것**이다.

`QUERY_LLM_MODEL` 이 없을 때 CLI 기본 모델로 도는 것보다 기동에 실패하는 것이 낫다.
전자는 몇 주간 잘못된 모델로 측정하게 만든다.

## 결과

**좋은 쪽**

- 값이 빠지면 즉시 죽는다. 측정 신뢰가 회복됐다
- 자격증명 폴백 사슬이 한곳으로 모였다
- 소스에서 기본 비밀번호가 사라졌다

**대가와 파생 사고**

- **clone 한 사람은 `.env` 없이 아무것도 못 돌린다.** `pnpm --filter api test:unit` 이
  테스트 파일 단위로 실패하는데, 설정 검증이 import 시점에 죽어서 원인이 안 보인다.
  README 와 `CLAUDE.md` 에 증상을 적어 두었다
- **e2e 가 운영 DB 를 물었다.** 앱 모듈을 파일 최상단에서 `require` 하면 설정이 `before()` 보다
  먼저 굳는다. `.env` 의 운영 URI 가 들어가 테스트가 운영 그래프에 붙었다.
  환경 고정 모듈을 `node --require` 로 선주입해 막고, 접속 대상을 단언하는 회귀 방지 테스트를 남겼다

두 번째가 이 결정의 진짜 대가다. 설정을 import 시점에 굳히면 **테스트가 그 시점을 앞지를 수 없다.**

## 교훈

**우연한 일치가 가장 위험하다.** 코드 기본값이 설정 파일과 같으면 설정이 안 읽혀도 정상으로 보인다.
그 상태로 하나만 달라지면 원인을 찾기 어렵다.
